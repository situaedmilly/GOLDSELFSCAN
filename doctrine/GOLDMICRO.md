GOLDMICRO is an execution microscope around an established Gold trading edge.

It asks:
Why did this particular entry realize, fail, arrive early, or arrive late?

It does not ask whether Gold has an edge.

PRIMARY EXECUTION FRAME: M5
PRECISION FRAME: M1
CONTEXT: M15 -> H1 -> H4
FORWARD WINDOW: +5m -> +25m

Core diagnostic dimensions:
EDGE | DIRECTION | ADMISSION | REALIZATION | EXIT

Admission classes:
EARLY | VALID | LATE | INVALID

Realization classes:
PRESENT | ABSENT

Exit classes should describe the observed exit condition without converting the observation into a trading recommendation.
